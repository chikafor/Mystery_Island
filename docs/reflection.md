The Python concept I understand now that I did not understand before is how different programming concepts work together to create a functional application.

Before this project, I understood some basic Python concepts, such as variables, input, output, and conditional statements. However, developing Mystery Island helped me understand how dictionaries, lists, functions, loops, and conditional statements can work together to manage information and control a program.

I also learned how to write automated tests using Python's unittest module to check whether my code works correctly.

One important lesson I gained is that programming is not just about writing code that works; it is also about testing, identifying mistakes, improving the code, and understanding why it works.
